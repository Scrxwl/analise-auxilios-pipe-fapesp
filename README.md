# Análise dos Auxílios PIPE — FAPESP

## Sobre o projeto

Este projeto apresenta uma análise dos projetos do programa PIPE da FAPESP,
com foco na evolução anual e na distribuição por área do conhecimento entre
2021 e 2025.

O objetivo foi transformar uma base pública extensa em informações mais
simples de interpretar por meio de um dashboard desenvolvido no Google Sheets.

## Objetivos

- Organizar e validar os dados disponibilizados pela FAPESP;
- Analisar a evolução dos projetos entre 2021 e 2025;
- Identificar as áreas com maior quantidade de projetos;
- Desenvolver um dashboard simples e de fácil interpretação.

## Fonte dos dados

Os dados foram obtidos na base pública da FAPESP.

- Fonte: [https://bv.fapesp.br/pt/266/]
- Data de acesso: [12/06/2026]
- Período analisado: 2021–2025

## Metodologia

Para esta análise, foram considerados como projetos os registros classificados
como “Auxílio à Pesquisa”.

O crescimento foi calculado pela fórmula:

Crescimento = (Projetos em 2025 - Projetos em 2021) / Projetos em 2021

## Ferramentas utilizadas

- Google Sheets
- Microsoft Excel
- Tabelas dinâmicas
- Fórmulas SOMA, SE e QUERY
- Gráficos de linhas e barras

## Principais análises

- Evolução anual da quantidade de projetos;
- Crescimento entre 2021 e 2025;
- Ranking das áreas com mais projetos em 2025;
- Projetos por Região e Cidade
- Construção de indicadores para acompanhamento dos resultados.

## Limitações

- A análise depende da classificação presente na base original;
- Registros sem área ou data válida foram desconsiderados;
- Os resultados representam o período e a data de extração informados.

## Tratamento dos dados

A análise foi construída inicialmente a partir da base pública da FAPESP.

A base bruta foi utilizada para gerar tabelas dinâmicas e indicadores.
Na versão disponibilizada neste repositório, a aba com os dados brutos foi
removida, mantendo apenas os resultados consolidados e o dashboard.

Essa decisão reduz o tamanho do arquivo e evita redistribuir integralmente
a base original. A fonte oficial está indicada abaixo para permitir a
rastreabilidade da análise.
